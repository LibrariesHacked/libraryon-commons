# LibraryCommons

LibraryCommons brings together stories, resources, and information about public libraries across the UK. It includes original articles from the British Library's LibraryOn team, community-written content, and a directory of 3,811 libraries across 218 authorities. Browse the site using the [site map](/sitemap/).
