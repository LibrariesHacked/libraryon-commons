# LibraryCommons

LibraryCommons brings together stories, resources, and information about public libraries across the UK. It includes original articles from the British Library's LibraryOn team, community-written content, and a directory of 4,238 current and historical library buildings across 218 authorities. Browse the site using the [site map](/sitemap/).

## Directory Data

The directory uses the [Public library data schemas](https://schema.librarydata.uk/) to structure data into individually editable JSON records. See the [migration audit and review procedure](migration/directory/README.md) for source priorities, ONS lookup evidence, unresolved records, and reproducible commands.
