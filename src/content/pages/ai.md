# Artificial Intelligence

LibraryCommons is an independent, community-driven project dedicated to celebrating, discovering, and maintaining open data about UK public libraries.

This statement sets out principles and practices regarding the use of Artificial Intelligence (AI) and machine learning tools across our website, code, and data pipelines.

## Respecting human creativity

We share the fundamental principles established in the [original LibraryOn AI statement](/archive/ai-statement/):

- **Human creativity:** We do not use generative AI to produce creative assets, illustrations, photography, or editorial features.
- **Authentic community content:** The articles preserved on this site—such as the special collections are authentic works, much of which are preserved from LibraryOn content.
- **Accurate public data:** We don't use AI to fabricate, invent, or guess library information. Details about library branches and local authority contacts are sourced from verified public sector publications, open council data, and community verification.
- **No training on private data:** We do not collect private personal data from our visitors, and we never feed private or non-public user data into AI training sets.

## Where AI is used in building LibraryCommons

We embrace modern developer tooling to make LibraryCommons robust, accessible, and sustainable as an open-source project. In preserving the original LibraryOn content, and library data, AI was an essential tool in extracting this as well as creating a new website and content management system - to precise specifications.

- **Code architecture and refactoring:** Migrating existing templates into clean, standards-compliant components
- **Accessibility testing:** Assisting with code auditing against WCAG 2.2 AA standards, keyboard navigation, high contrast ratios, and screen reader semantic HTML across all pages.
- **Data validation pipelines:** Generating automated tests and validation scripts that validate data, postcode formats, coordinate geometry, and schema integrity for more than 3,000 public library locations.
- **Search indexing logic:** Optimizing client-side search and filtering algorithms
- **Linting and code formatting:** Enforcing consistent code style and formatting standards

## Open source

Code and content published on LibraryCommons is reviewed, tested, and verified by humans:

- **Human-in-the-loop:** No automated tool or AI system has autonomous commit rights to publish unreviewed content to the live site. Code changes pass through automated test suites and human review.
- **Open-source and inspectable:** All source code, data transformation scripts, and test suites are public and open source on [GitHub](https://github.com/LibrariesHacked/libraryon-commons).
- **Community maintenance:** If you notice any factual errors you can submit an update through the directory interface or open an issue on GitHub.
