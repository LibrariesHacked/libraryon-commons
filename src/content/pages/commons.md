# LibraryCommons

LibraryCommons is a project built on the resources originally shared by LibraryOn and The British Library.

We preserve that original work with credits intact, while creating space for new resources and a library branch directory that the library community can continue to maintain.

## Shared knowledge

Library collections and experience have value beyond any single programme. The Commons brings them together as a resource that can keep growing.

## Community stewardship

Contributors can add new work and help maintain library and authority listings. Original LibraryOn articles retain original wording and attribution. New contributions should identify authors and sources, with permission for any images, documents or other material they include.

## Open

Content is shared under Creative Commons Attribution 4.0 unless a different licence or exception is stated.

LibraryCommons is not the original LibraryOn service and is not presented as an official British Library website.
